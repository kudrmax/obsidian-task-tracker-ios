# Task Calendar for iPhone — deprecated

This repository is no longer used. The iPhone app moved, with its whole history, into the plugin's repository:

**https://github.com/kudrmax/obsidian-task-tracker** (folder [`apple/`](https://github.com/kudrmax/obsidian-task-tracker/tree/master/apple))

The plugin and the Apple apps now live in one repository and share one core: the rules of the tasks file are written once, in TypeScript, and the apps run them in JavaScriptCore. Build and setup instructions are in that repository's README.
